# Hurricanes And Gas Prices

## Project Description:
In this project we aim to create a predictive model that can utilize indicators of a hurricane’s progression to estimate the best time to start preparing for the hurricane as indicated by gas prices. Predicting gas prices can give insights into other changes in the economy that can take place when a natural disaster is imminent. It can also help those in the path of the hurricane stock up on fuel that may be needed for evacuation or running backup generators. In order to implement a comparison of impacts due to variation in population, we will examine data from Florida, the Gulf, and Miami. We plan to utilize comparison analysis between these areas and decision trees.

A thorough understanding of the impact of hurricanes and large scale natural weather disasters is imperative for the wellbeing of the citizens of Florida and the southern economies. This understanding would benefit Floridians by providing insight into how to best prepare for extreme weather events based on the phases of a developing hurricane.
